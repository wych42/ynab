# 体验发布的已知边界

产品代码版本为 `d4bb3d1`。独立全量测试通过 91 个文件、757 条测试，已确认的 P0 产品缺陷均已在真实浏览器复验关闭。按用户先体验的目标部署；这不代表全部 147 条验收用例均已完整通过。

## 原生辅助技术仍需人工检查

键盘操作、焦点恢复、角色、实时播报属性和文字内容均有浏览器证据。原生屏幕阅读器的实际朗读未执行；浏览器原生 200% 缩放也未成功触发，仅有 CSS 200% 放大的布局证据。继续保留这些验证边界，不将 DOM 契约当作完整听读结果。

## 估值日期边界需要补齐

验收用例 `MC-UI-NW-009` 的 P2 边界尚未全部满足：非法日期显示通用错误并可编辑日期，未来日期仍可请求估值。后续应统一合法估值日期范围、回退原因及可恢复操作。当前体验优先使用当天或历史日期。
